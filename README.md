# Planta Tagger

This project provides a simple Flask service that detects floor plan types in PDF files.

## Installation

Install the dependencies with:

```bash
pip install -r requirements.txt
```

## Usage

Run the service locally with:

```bash
python main.py
```

The server listens on port `5000` and exposes the `/identificar_plantas` endpoint.
